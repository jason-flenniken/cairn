# How is the on-track verdict decided?

**Decision:** The CLI computes green, yellow or red from a fixed cairn-direction scorecard; red blocks phase approval, yellow can be approved, and a re-plan or later code commit invalidates the verdict.

**Why:** The model cannot pick the colour, and the worst cases cannot slip through.
