# What does the pane's spend bar count?

**Decision:** This plan's cost and tokens in this session only, reset on restart; agent cards show ~$ estimates from a built-in price table; spend is never persisted, capped, or written to the record.

**Why:** Claude Code reports dollars only as a session total, and cross-session spend was declined.
