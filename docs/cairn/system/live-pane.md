## Rules

- Keep `register.tsx` a wiring file. The engine allows one unmatched `session.start` hook per module, so all start work runs in order from the one handler (`plugins/cairn/hooks/register.tsx:9`).
- A module's start work is best effort. A failing module never stops the others or the session (`register.tsx:14-33`).
- Mod command names use `-`, never `:`, because the engine forbids it (`hooks/mod/pause.ts:198`).
- Measure bar widths in terminal cells, not characters (`hooks/mod/bar.tsx:24`, `:65`).
- Do not set a `backgroundColor` on the pane. Claude Code paints the docked pane and ignores it.
- The pane polls every 2 seconds and opens 48 columns wide (`hooks/mod/pane.tsx:34`, `:37`).
- Pause writes `handoff.md` first, then runs `cairn pause` (`hooks/mod/pause.ts:124-136`).
- Every `$.state` key the mod uses is declared in `plugins/cairn/types/index.d.ts`, and that file has no `import`; `claude plugin validate` enforces it.
- Helpers that take `$` are `function` declarations, not `const` arrows, and use no `import * as` calls (`hooks/NOTES.md`, agent cards).
- Spend counts this plan's cost in this session only. It resets on restart and is never saved or capped (`hooks/mod/usage.ts`).
- Mod changes need `/reload-plugins`. Mod tests live under `hooks/test/` and run with `npm run test:mod`.

## How it works

`register.tsx` only wires the one-concern modules under `hooks/mod/`: guards, approvals, pause, the pane and agent activity. Its single `session.start` handler runs the heartbeat, pause, activity and pane start work in turn.

The pane has three tabs, Now, History and Records (`pane.tsx:26-30`), with a bar pinned to the bottom. Now shows fixed-height cards, the main session first, and each agent card shows its role, the plan's stage and step, and an estimated cost. The cards come from the engine's agent list and are updated by tool, turn and step events in `activity.ts`. A card's full width is one button, so a click anywhere on it switches to that agent.

The bar (`bar.tsx`) shows the git line, the usage lines and the stage steps, wrapped to the pane width. Usage comes from the engine's session measure events (`usage.ts`), with prices from a built-in table (`prices.ts`). Inline, in the 7-row pane, the bar shrinks to one line.

The mod learns the plan's state by running `cairn status --json` through `cli.ts`, and it never reads `state.json` itself. A poll checks file stats and reads again only when something changed. Pause and resume are in `pause.ts`. Pause is instant even mid-turn, and Stop now cuts the running turn. After the cache window the user runs `/clear` and then `/cairn:resume`, which loads only state, the handoff and status.
