Branches now use standard names. New plans use `feature/<slug>` or `fix/<slug>`, and tasks use `task/<slug>/<task>`, replacing `sdlc/` and `sdlc-task/` names that read as tool plumbing in a branch list or PR. Worktree folders are named after the branch. Lookup keys on the branch the plan recorded, so hand-made branches are never mistaken for plans, and old `sdlc/` plans finish under their old names. The pane's Approve card now appears only when an approval would pass (`ready` in `status --json`), shows what is being approved with Read all, and approving there answers a later chat question for the same stop. Clicking an agent card opens its conversation.
