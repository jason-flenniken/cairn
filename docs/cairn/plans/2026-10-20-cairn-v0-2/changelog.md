cairn 0.2 made approvals provably the user's and put plan state in a live pane. Before, the model relayed approvals itself, pausing needed an agent turn, and bugs had no light path. Approvals and overrides now need proof: the mod holds a random secret in memory and writes only its SHA-256, which the CLI accepts once, or you run `--human` in a terminal. The model cannot approve or write `state.json`. Added the `/cairn-pane` pane and status line, instant pause and Stop now, a CLI-scored drift verdict at each phase end (`direction-checker`, `/cairn:direction`), the repro-first `/cairn:fix` lane, and `--file` and `--note-file` for long text.
