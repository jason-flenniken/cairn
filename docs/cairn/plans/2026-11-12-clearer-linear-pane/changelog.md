The Linear tab was unreadable on a large project. Running work was buried, most issues showed red as blocked, and nothing named the ticket being built. A new pure module, `cli/src/board.ts`, now computes the board's status sections: In progress, Ready to start (sorted by what each item unblocks), Waiting (one row per epic) and Done. It also warns about epic-level links that hold back 3 or more sub-issues. `cairn linear board` and the pane both draw these sections, and the pane strips escape and bidi characters from Linear text. The board JSON only gains fields. Plan rows gain `taskIssues` and `epic`, so cards, the plan header and UP NEXT show ticket keys. Four card fixes are included. Version 0.13.0.
