The Linear tab was unreadable on a large project. Running work was buried, most issues showed red as blocked, and nothing named the ticket being built. `cairn linear board` now computes status sections in a new pure module, `cli/src/board.ts`: In progress, Ready to start (sorted by how much each item unblocks), Waiting (one row per epic), and Done. It also warns about epic-level blocked-by links that hold back 3 or more sub-issues. The text board and the pane draw these sections, and the pane strips escape and bidi characters from Linear text. The board JSON gains fields, but nothing is removed. Plan rows carry `taskIssues` and `epic`, so cards, the plan header and UP NEXT show ticket keys. The plan also includes four card fixes. Version 0.13.0.
